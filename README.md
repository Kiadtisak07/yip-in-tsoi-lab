ยินดีต้อนรับสู่โปรเจกต์ **YIP IN TSOI LAB** พื้นที่จำลองการสร้างสรรค์นวัตกรรม AI ภายในองค์กร (Internal AI Innovation Playground) ที่ออกแบบมาเพื่อให้ทุกทีมภายในบริษัทสามารถนำเสนอ ตรวจสอบ และผลักดันโซลูชัน AI จากระดับแนวคิดทดลองไปสู่ผลิตภัณฑ์ที่พร้อมออกสู่ตลาดจริง

---

## 1. ข้อมูลภาพรวมของระบบ (System Overview)
### ฟังก์ชันหลักของระบบ (Core Features)
1. **Interactive Dashboard:** แสดงสถิติจำนวนไอเดียจำแนกตามสถานะ (Total Ideas, In Sandbox, Production Ready, Commercialized) พร้อมแอนิเมชันนับตัวเลขแบบไดนามิก
2. **Filter & Search Asset System:** ค้นหาและคัดกรองเครื่องมือ AI ตาม "ทีมที่พัฒนา (Team)" หรือ "กลุ่มธุรกิจ (Domain)" โดยใช้ระบบ Sub-category Chips
3. **Project Add / Submission System:** ระบบกรอกแบบฟอร์มเพื่อเสนอแนวคิดนวัตกรรม AI ใหม่ พร้อมระบบตรวจสอบข้อมูลเบื้องต้น (Client-side Validation) และการนับจำนวนอักขระแบบเรียลไทม์
4. **Upvote & Persistence Mechanism:** สมาชิกในองค์กรสามารถกดโหวต (Upvote) ให้กับไอเดียที่ชื่นชอบ โดยระบบจะบันทึกสถานะการโหวตไว้ใน `localStorage` ของเบราว์เซอร์เพื่อป้องกันการกดซ้ำเมื่อรีเฟรชหน้าเว็บ
5. **Success Stories Area:** พื้นที่แสดงผลงานความสำเร็จ (Hall of Fame) สำหรับไอเดียที่ถูกพัฒนาไปจนสร้างรายได้และใช้งานได้จริงในเชิงพาณิชย์
6. **Responsive Support:** รองรับการแสดงผลทุกขนาดหน้าจอ ตั้งแต่เดสก์ท็อป แท็บเล็ต ไปจนถึงสมาร์ทโฟน ด้วยเมนูสไลด์ด้านข้างสำหรับอุปกรณ์เคลื่อนที่

## 2. โครงสร้างไฟล์ของโปรเจกต์ (Project Structure)

โปรเจกต์นี้ประกอบด้วย 3 ไฟล์หลักในโฟลเดอร์ทำงาน:

```text
├── index.html       # โครงสร้าง HTML, โครงสร้างเมนู, ส่วนจัดวาง และองค์ประกอบของ Modal ทั้งหมด
├── main.js          # ส่วนควบคุม Logic, ข้อมูลจำลอง (Mock Data), ระบบค้นหา คัดกรอง และการจัดเก็บข้อมูลเบื้องต้น
└── style.css        # ระบบดีไซน์ (Design System), ตัวแปร CSS (Variables), เอฟเฟกต์แอนิเมชัน และการจัดหน้าตามสเกล
