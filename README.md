# 🚀 YIP IN TSOI LAB

ยินดีต้อนรับสู่โปรเจกต์ **YIP IN TSOI LAB** พื้นที่จำลองการสร้างสรรค์นวัตกรรม AI ภายในองค์กร (Internal AI Innovation Playground) ที่ออกแบบมาเพื่อให้ทุกทีมภายในบริษัทสามารถนำเสนอ ตรวจสอบ และผลักดันโซลูชัน AI จากระดับแนวคิดทดลองไปสู่ผลิตภัณฑ์ที่พร้อมออกสู่ตลาดจริง

---

## 1. ข้อมูลภาพรวมของระบบ (System Overview)

### ฟังก์ชันหลักของระบบ (Core Features)
* **Interactive Dashboard:** แสดงสถิติจำนวนไอเดียจำแนกตามสถานะ (Total Ideas, In Sandbox, Production Ready, Commercialized) พร้อมแอนิเมชันนับตัวเลขแบบไดนามิก
* **Filter & Search Asset System:** ค้นหาและคัดกรองเครื่องมือ AI ตาม "ทีมที่พัฒนา (Team)" หรือ "กลุ่มธุรกิจ (Domain)" โดยใช้ระบบ Sub-category Chips
* **Project Add / Submission System:** ระบบกรอกแบบฟอร์มเพื่อเสนอแนวคิดนวัตกรรม AI ใหม่ พร้อมระบบตรวจสอบข้อมูลเบื้องต้น (Client-side Validation) และการนับจำนวนอักขระแบบเรียลไทม์
* **Upvote & Persistence Mechanism:** สมาชิกในองค์กรสามารถกดโหวต (Upvote) ให้กับไอเดียที่ชื่นชอบ โดยระบบจะบันทึกสถานะการโหวตไว้ใน `localStorage` ของเบราว์เซอร์ เพื่อป้องกันการกดซ้ำเมื่อรีเฟรชหน้าเว็บ
* **Success Stories Area:** พื้นที่แสดงผลงานความสำเร็จ (Hall of Fame) สำหรับไอเดียที่ถูกพัฒนาไปจนสร้างรายได้และใช้งานได้จริงในเชิงพาณิชย์
* **Responsive Support:** รองรับการแสดงผลทุกขนาดหน้าจอ ตั้งแต่เดสก์ท็อป แท็บเล็ต ไปจนถึงสมาร์ทโฟน ด้วยเมนูสไลด์ด้านข้างสำหรับอุปกรณ์เคลื่อนที่

## 2. โครงสร้างไฟล์ของโปรเจกต์ (Project Structure)

โปรเจกต์นี้ประกอบด้วยไฟล์หลักดังนี้:

```text
├── .vscode/             # การตั้งค่าโปรเจกต์
├── scripts/             # สคริปต์สำหรับจัดการข้อมูลโครงการ (update_project.js)
├── dashboard.html       # หน้า Dashboard สำหรับวิเคราะห์ Metrics
├── index.html           # โครงสร้างหลัก (เมนู, ส่วนแสดงไอเดีย, Modal ต่างๆ)
├── login.html           # หน้าสำหรับเข้าสู่ระบบจัดการ
├── main.js              # Logic การทำงาน, Mock Data, ระบบ CRUD และการโหวต
├── style.css            # ระบบดีไซน์ (Design System), CSS Variables และแอนิเมชัน
└── logo.png             # โลโก้โปรเจกต์
